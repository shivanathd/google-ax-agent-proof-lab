## Evidence labels

Use DOCUMENTED for a sourced product capability, DESIGNED for a proposed mechanism, EXECUTED for an actual test with artifacts, and UNKNOWN for missing proof. A source citation cannot turn a planned integration into an executed one.

## Claim ledger template

Each future public claim must contain `claim_id`, wording, evidence label, source URL or run ID, tested revision, profile, scope, limitations and reviewer status. Do not auto-fill result claims from the expected values in the tests. The ledger itself is [`CLAIM_LEDGER.md`](CLAIM_LEDGER.md).
